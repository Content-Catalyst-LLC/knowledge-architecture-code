# Governance Checklist

## Interface and Information Architecture

- [ ] Main library links are current.
- [ ] Article map links are current.
- [ ] Gateway navigation points to article maps and related pillars.
- [ ] Related-article sections include only published links.
- [ ] Table of contents reflects the article structure.

## Metadata

- [ ] Each article has title, slug, excerpt, category, series, focus keyword, tags, and image metadata.
- [ ] Repository-supported articles include a repository path.
- [ ] Status and date-reviewed fields are maintained.
- [ ] Synthetic datasets are clearly marked.

## Taxonomy and Semantics

- [ ] Categories have scope notes.
- [ ] Relationship types are controlled and documented.
- [ ] Concepts are distinguished from articles, sources, methods, datasets, and repositories.
- [ ] Cross-domain concepts include context.

## Repository Alignment

- [ ] Article folders match article slugs.
- [ ] README files explain purpose and scope.
- [ ] Data dictionaries exist where data exists.
- [ ] Outputs are reproducible or documented.
- [ ] SQL schemas match article concepts.

## AI Retrieval and Trust

- [ ] Retrieval context includes metadata and provenance.
- [ ] AI-facing summaries distinguish evidence from examples.
- [ ] Relationship uncertainty is documented where needed.
- [ ] Source diversity and marginalized perspectives are reviewed.
