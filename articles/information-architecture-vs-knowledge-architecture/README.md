## Purpose

This scaffold compares **information architecture** and **knowledge architecture** as two related but distinct layers of a serious knowledge system.

Information architecture focuses on the visible organization of information: navigation, labels, menus, categories, page pathways, search, and user experience.

Knowledge architecture focuses on the intellectual structure beneath the interface: concepts, semantic relationships, evidence pathways, metadata, taxonomies, ontologies, repositories, knowledge graphs, and governance.
