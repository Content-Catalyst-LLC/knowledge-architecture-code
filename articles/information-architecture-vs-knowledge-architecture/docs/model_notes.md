# Model Notes: Information Architecture vs. Knowledge Architecture

## Core Distinction

Information architecture (IA) organizes information environments so users can find and navigate content.

Knowledge architecture (KA) organizes meaning so users and systems can understand relationships among concepts, evidence, data, methods, repositories, and governance structures.

## Modeling Approach

This scaffold treats the comparison as a two-layer architecture:

1. **Navigational layer**
   - pages
   - article maps
   - menus
   - links
   - visible pathways

2. **Semantic layer**
   - concepts
   - relationship types
   - evidence status
   - repository support
   - metadata context
   - governance notes

## Key Audit Questions

- Is every major knowledge object visible through navigation?
- Is every visible object semantically contextualized?
- Are article-to-repository relationships explicit?
- Are related articles merely linked, or are their relationships typed?
- Are concepts defined separately from pages?
- Are evidence, method, source, and repository roles preserved?
