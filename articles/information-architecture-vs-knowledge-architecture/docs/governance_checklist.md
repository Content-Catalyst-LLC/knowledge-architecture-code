# Governance Checklist

## Information Architecture Review

- [ ] Main navigation is clear.
- [ ] Article map links are current.
- [ ] Related-article sections do not link to nonexistent articles.
- [ ] Repository links are visible where companion code exists.
- [ ] Labels are readable and consistent.

## Knowledge Architecture Review

- [ ] Concepts are defined separately from pages.
- [ ] Relationships are typed rather than generic.
- [ ] Metadata distinguishes article, source, dataset, method, and repository.
- [ ] Evidence links include provenance or rationale.
- [ ] Repository folders mirror article slugs.
- [ ] Revision history is preserved for major structural changes.

## IA/KA Alignment Review

- [ ] Every semantically important object has a visible navigation path.
- [ ] Every highly visible object has semantic context.
- [ ] Article maps, metadata, and repository folders reinforce each other.
- [ ] AI retrieval can distinguish content objects from knowledge objects.
