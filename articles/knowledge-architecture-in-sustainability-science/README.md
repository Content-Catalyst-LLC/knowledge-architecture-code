# Knowledge Architecture in Sustainability Science

This folder contains professional companion assets for the article:

**Knowledge Architecture in Sustainability Science**

GitHub article folder:

https://github.com/Content-Catalyst-LLC/knowledge-architecture-code/tree/main/articles/knowledge-architecture-in-sustainability-science

## Purpose

This scaffold models knowledge architecture in sustainability science: coupled human-environment systems, sustainability objects, concepts, indicators, datasets, models, policies, places, communities, governance records, justice context, scale context, uncertainty, evidence types, and relationship traceability.

The examples are synthetic but designed for serious sustainability-science and research-platform analysis. They can be adapted to SDG indicators, planetary-boundary indicators, geospatial layers, policy records, model metadata, community-governed datasets, article maps, and AI-assisted retrieval workflows.

## Repository Structure

- `python/` — sustainability object, scale, justice, metadata, relationship, and review diagnostics
- `r/` — coverage summaries, scale summaries, and sustainability-system diagnostics
- `julia/` — sustainability architecture quality metrics
- `sql/` — schemas for sustainability objects, systems, concepts, evidence, indicators, models, places, communities, relationships, governance records, and revisions
- `rust/` — CLI-style sustainability validation scaffold
- `go/` — lightweight coverage utility
- `cpp/` — efficient diagnostic metric examples
- `fortran/` — numerical sustainability-quality metric example
- `c/` — low-level coverage metric example
- `docs/` — model notes, data dictionary, governance checklist, and runbook
- `data/` — small synthetic sustainability datasets
- `outputs/` — expected/generated outputs
