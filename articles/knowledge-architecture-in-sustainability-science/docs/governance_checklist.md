# Governance Checklist

## Metadata and Scale

- [ ] Every object has title, type, status, and source context.
- [ ] Spatial scale is documented.
- [ ] Temporal scale or review date is documented where relevant.
- [ ] Dataset, model, indicator, policy, and community-record objects are distinguished.

## Evidence and Uncertainty

- [ ] Evidence type is documented.
- [ ] Model assumptions are documented.
- [ ] Indicator definitions and limitations are documented.
- [ ] Scenario outputs are not treated as predictions without context.
- [ ] Synthetic data is clearly marked.

## Justice and Community Governance

- [ ] Affected communities are documented where relevant.
- [ ] Distributional effects are considered.
- [ ] Community-governed knowledge includes access and consent context.
- [ ] Sensitive ecological or vulnerable-community data is not automatically open.
- [ ] Historical responsibility or vulnerability context is recorded where relevant.

## Relationship Governance

- [ ] Relationships are typed.
- [ ] Relationships include provenance notes.
- [ ] Generic "related" links are reviewed.
- [ ] Social-ecological feedbacks are preserved where relevant.

## AI Retrieval Governance

- [ ] AI retrieval distinguishes data, models, indicators, policy, and community records.
- [ ] AI summaries preserve scale, uncertainty, and justice context.
- [ ] AI-generated metadata is reviewed before publication.
