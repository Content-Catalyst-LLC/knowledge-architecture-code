# Model Notes: AI and Knowledge Organization

## Core Idea

AI and knowledge organization meet where artificial intelligence systems retrieve, classify, summarize, recommend, and generate knowledge from structured and semi-structured knowledge environments. The reliability of AI-assisted knowledge work depends on metadata, taxonomy, ontology, provenance, source hierarchy, retrieval evaluation, human review, and governance.

## Core Layers

1. **Knowledge-object layer**
   - articles
   - sources
   - datasets
   - metadata schemas
   - taxonomies
   - ontologies
   - knowledge graphs
   - embedding indexes
   - retrieval records
   - AI outputs
   - review records
   - correction records

2. **Metadata layer**
   - title
   - source type
   - author or institution
   - date
   - version
   - license
   - review status
   - evidence type
   - sensitivity
   - audience
   - jurisdiction or domain scope

3. **Semantic-structure layer**
   - controlled vocabularies
   - taxonomies
   - thesauri
   - ontology classes
   - relationship types
   - authority files
   - source hierarchy rules

4. **AI retrieval layer**
   - corpus registry
   - chunking strategy
   - embedding index
   - vector retrieval
   - keyword retrieval
   - graph retrieval
   - hybrid retrieval
   - retrieval evaluation

5. **RAG and grounding layer**
   - retrieved source
   - source rank
   - citation
   - output grounding
   - claim-to-source link
   - source-context preservation
   - hallucination review

6. **Governance layer**
   - human review
   - taxonomy change log
   - metadata correction
   - AI-generated label status
   - source hierarchy review
   - equity and representation review
   - sensitive-knowledge controls

## Key Review Questions

- Are knowledge objects described with required metadata?
- Are AI outputs connected to sources, citations, or retrieval records?
- Are taxonomy and ontology updates versioned?
- Are AI-generated labels treated as provisional until reviewed?
- Are retrieval failures captured and used to improve the system?
- Are source hierarchy rules explicit?
- Are marginalized and sensitive knowledge contexts handled responsibly?
- Are correction and human-review records preserved?
