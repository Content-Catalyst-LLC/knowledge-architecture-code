# Validation Checklist

Use this checklist when reviewing hierarchical knowledge structures.

- [ ] Does every non-root node have a valid parent?
- [ ] Are root nodes intentional?
- [ ] Are parent-child relationships genuinely broader-narrower relationships?
- [ ] Are associative relationships kept separate from hierarchy?
- [ ] Are abstraction levels consistent among sibling nodes?
- [ ] Are overloaded parent nodes candidates for subdivision?
- [ ] Are very deep branches justified?
- [ ] Are orphaned articles or nodes identified?
- [ ] Are interdisciplinary concepts supported through cross-links, facets, or polyhierarchy?
- [ ] Are scope notes and governance rules documented?
