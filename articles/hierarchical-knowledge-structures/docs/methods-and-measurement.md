# Methods and Measurement

This article folder treats hierarchical knowledge structures as inspectable systems.

Core diagnostics include:

- node count
- root count
- maximum depth
- mean and median depth
- breadth by level
- branching factor by parent
- leaf rate
- orphan detection
- missing-parent detection
- cycle detection
- polyhierarchy detection
- article-to-node assignment review

These diagnostics should guide editorial and architectural review, not replace interpretation. A deep branch may represent appropriate domain complexity; it may also represent navigational burden. A high branching factor may represent a broad domain; it may also indicate an overloaded parent category.
