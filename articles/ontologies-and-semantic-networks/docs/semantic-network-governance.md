# Semantic-Network Governance

Semantic networks require governance because relationship meanings can drift.

Governance checklist:

- Maintain preferred labels and alternate labels
- Define relationship types before applying them
- Preserve scope notes for ambiguous concepts
- Track deprecated classes, properties, and terms
- Keep revisions visible
- Validate required metadata fields
- Distinguish equivalence, similarity, dependency, evidence, and adjacency
- Review high-degree hubs for conceptual overload
- Review orphaned nodes for weak integration or future expansion
