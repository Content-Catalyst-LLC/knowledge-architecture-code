# Validation Notes

Validation should check both structure and meaning.

## Structural validation

- Every relationship source and target should exist in `concepts.csv`.
- Every pathway concept should exist in `concepts.csv`.
- Relationship types should be controlled and documented.
- Evidence status should use a controlled set of values.
- Outputs should be reproducible from source data.

## Interpretive validation

- Relationship labels should preserve meaning.
- Evidence status should not overstate support.
- Concept boundaries should be clear.
- Conceptual maps should remain revisable.
- Cross-domain relationships should not imply false equivalence.
