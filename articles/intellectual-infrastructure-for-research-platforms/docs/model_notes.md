# Model Notes: Intellectual Infrastructure for Research Platforms

## Core Idea

Intellectual infrastructure is the durable foundation that allows a research platform to preserve meaning, evidence, reproducibility, relationships, governance, and revision history over time.

## Infrastructure Layers

1. **Interface layer**
   - navigation
   - article maps
   - tables of contents
   - related articles
   - repository links

2. **Editorial layer**
   - titles
   - excerpts
   - captions
   - references
   - series context
   - article standards

3. **Conceptual layer**
   - concepts
   - frameworks
   - models
   - research pathways
   - article sequences

4. **Metadata layer**
   - slugs
   - status
   - categories
   - tags
   - repository paths
   - evidence status
   - review dates

5. **Semantic layer**
   - taxonomies
   - ontologies
   - controlled vocabularies
   - relationship types
   - knowledge graphs

6. **Reproducibility layer**
   - code
   - data
   - notebooks
   - SQL schemas
   - outputs
   - validation scripts

7. **Governance layer**
   - revision logs
   - naming standards
   - review cycles
   - source review
   - AI retrieval rules
   - stewardship checklists

## Key Audit Questions

- Does every article have metadata?
- Do repository-supported articles have matching folders?
- Are semantic relationships typed?
- Are evidence relationships traceable?
- Are repository assets documented?
- Are outputs reproducible or explained?
- Are governance records current?
- Can AI retrieval distinguish article, dataset, method, source, output, and repository objects?
