# Governance Checklist

## Project and Collaboration

- [ ] Research question is documented.
- [ ] Contributors and roles are documented.
- [ ] Institutions and project governance are visible.
- [ ] Authorship and credit expectations are recorded.
- [ ] Decision logs and revision records are preserved.

## Data, Methods, and Reproducibility

- [ ] Datasets include metadata and data dictionaries.
- [ ] Protocols include version and deviation notes.
- [ ] Software includes environment and dependency documentation.
- [ ] Analysis outputs are linked to scripts and source data.
- [ ] Expected outputs and reproducibility checks are stored.

## Open Science and FAIR

- [ ] Research outputs have persistent identifiers where applicable.
- [ ] Data are findable, accessible, interoperable, and reusable where ethical.
- [ ] License and access rules are clear.
- [ ] Repository structure supports reuse.
- [ ] Metadata and provenance support long-term stewardship.

## Ethics and Equity

- [ ] Ethics approvals and consent conditions are connected to relevant objects.
- [ ] Sensitive data and community-governed knowledge are protected.
- [ ] Local, technical, junior, and community contributions are visible.
- [ ] Data extraction and reuse are reviewed for equity.
- [ ] Global collaboration avoids extractive knowledge practices.

## AI-Assisted Scientific Collaboration

- [ ] AI-generated summaries, metadata, code, or classifications are labeled.
- [ ] AI outputs are reviewed before scientific use.
- [ ] AI-assisted literature search preserves source provenance.
- [ ] AI-generated code is tested.
- [ ] AI-generated hypotheses are separated from evidence.
