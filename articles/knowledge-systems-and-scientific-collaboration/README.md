# Knowledge Systems and Scientific Collaboration

This folder contains professional companion assets for the article:

**Knowledge Systems and Scientific Collaboration**

GitHub article folder:

https://github.com/Content-Catalyst-LLC/knowledge-architecture-code/tree/main/articles/knowledge-systems-and-scientific-collaboration

## Purpose

This scaffold models scientific collaboration knowledge systems: research projects, contributors, institutions, contributor roles, datasets, protocols, software artifacts, publications, peer review, ethics records, provenance relationships, open-science readiness, FAIR data coverage, reproducibility readiness, AI-assisted research review, and collaboration-governance infrastructure.

The examples are synthetic but designed for serious open-science, team-science, data-stewardship, scientific-reproducibility, multi-institution collaboration, research-infrastructure, and AI-assisted scientific collaboration analysis.

## Repository Structure

- `python/` — contributor, metadata, provenance, reproducibility, ethics, review, and relationship diagnostics
- `r/` — collaboration-network, contributor-role, metadata, provenance, and reproducibility summaries
- `julia/` — scientific collaboration knowledge-system quality metrics
- `sql/` — schemas for research projects, institutions, contributors, roles, datasets, protocols, software artifacts, publications, ethics records, relationships, peer review, and revisions
- `rust/` — CLI-style scientific collaboration validation scaffold
- `go/` — lightweight reproducibility and provenance coverage utility
- `cpp/` — efficient diagnostic metric examples
- `fortran/` — numerical collaboration-quality metric example
- `c/` — low-level coverage metric example
- `docs/` — model notes, data dictionary, governance checklist, and runbook
- `data/` — small synthetic scientific collaboration datasets
- `outputs/` — expected/generated outputs
