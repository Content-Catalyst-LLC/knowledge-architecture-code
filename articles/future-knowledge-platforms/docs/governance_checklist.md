# Governance Checklist

## Semantic Architecture

- [ ] Knowledge objects are typed.
- [ ] Required metadata fields are defined.
- [ ] Taxonomy terms have scope notes.
- [ ] Relationship types are defined and reviewed.
- [ ] Knowledge graph relationships include provenance.

## AI-Assisted Discovery

- [ ] AI retrieval records preserve query, source, rank, and grounding context.
- [ ] AI outputs include source or retrieval links.
- [ ] AI-generated metadata and relationships are marked provisional.
- [ ] AI output review status is visible.
- [ ] Correction records can improve metadata, taxonomy, and retrieval.

## Reuse and Repository Infrastructure

- [ ] Articles link to relevant code/data repositories.
- [ ] Repositories include README, license, data dictionary, and runbook where relevant.
- [ ] Reuse conditions are documented.
- [ ] Code examples include expected outputs.
- [ ] Sensitive or restricted knowledge has access conditions.

## Accessibility and Learning

- [ ] Pages use semantic structure.
- [ ] Images include alt text and captions.
- [ ] Video/audio assets include captions or transcripts where applicable.
- [ ] Article maps support learning pathways.
- [ ] Beginner, intermediate, and advanced pathways are considered.

## Trust, Equity, and Stewardship

- [ ] Source hierarchy rules are documented.
- [ ] Marginalized perspectives and excluded knowledge are reviewed.
- [ ] Sensitive or community-governed knowledge is protected.
- [ ] Revision and correction logs are maintained.
- [ ] Link checks, dependency checks, and review cycles are scheduled.
- [ ] Platform export, backup, and migration plans exist.
