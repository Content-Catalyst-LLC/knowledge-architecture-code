# Model Documentation

## Concept Model

A concept is represented as a reusable intellectual unit with an identifier, label, domain, depth, and status.

## Relationship Model

A relationship connects two concepts and includes a relationship type and weight.

## Knowledge Graph Model

The graph model represents concepts as nodes and relationships as edges.

```text
G = (V, E)
```

where `V` is the set of concepts and `E` is the set of semantic, structural, or navigational relationships.
