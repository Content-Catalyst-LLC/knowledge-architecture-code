# Methods and Measurement

This folder treats knowledge architecture as a measurable system without reducing interpretation to metrics.

Useful diagnostics include:

- concept count
- relationship count
- average taxonomy depth
- maximum taxonomy depth
- degree centrality
- bridge-node detection
- orphan concept detection
- category/domain balance
- metadata completeness
- schema validity
- article-map coverage

These measures should be interpreted alongside editorial judgment, disciplinary context, governance rules, and reader needs.
