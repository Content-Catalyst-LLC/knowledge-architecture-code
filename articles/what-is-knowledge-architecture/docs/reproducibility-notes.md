# Reproducibility Notes

The examples use small synthetic datasets stored in `data/`.

## Suggested Execution Order

1. Run the Python graph analysis.
2. Run the R taxonomy audit.
3. Inspect the SQL schema.
4. Compile and run systems-language examples where useful.
5. Compare generated outputs in `outputs/`.

## Data Notes

The datasets are synthetic and educational. They are designed to demonstrate how concepts, articles, relationships, metadata fields, and governance structures can be represented computationally.
