# Model Notes: Conceptual Modeling in Complex Systems

## Core Idea

Conceptual modeling in complex systems organizes boundaries, components, relationships, feedback loops, assumptions, evidence, uncertainty, and governance into a structured representation of how a system is believed to work.

## Core Layers

1. **System layer**
   - system title
   - system type
   - scope note
   - boundary note
   - spatial scale
   - temporal scale
   - review status

2. **Component layer**
   - drivers
   - stocks
   - flows
   - agents
   - variables
   - institutions
   - feedback processes
   - emergent properties

3. **Relationship layer**
   - causes
   - increases
   - decreases
   - buffers
   - amplifies
   - constrains
   - feedsBackTo
   - triggersThreshold
   - delays
   - mediates

4. **Feedback layer**
   - reinforcing loops
   - balancing loops
   - policy-resistance loops
   - adaptation loops
   - trust loops
   - resource-allocation loops

5. **Evidence layer**
   - empirical data
   - literature review
   - stakeholder review
   - simulation output
   - model documentation
   - community knowledge
   - expert judgment

6. **Uncertainty layer**
   - data uncertainty
   - parameter uncertainty
   - structural uncertainty
   - behavioral uncertainty
   - scenario uncertainty
   - value uncertainty

7. **Governance layer**
   - model review
   - equity review
   - assumption review
   - AI-generated relationship review
   - revision history
   - access restrictions

## Key Review Questions

- Are model boundaries explicit?
- Are components defined and typed?
- Are relationships directional and typed?
- Do relationships include provenance?
- Are feedback loops identified?
- Are assumptions documented?
- Are uncertainties visible?
- Can the model be revised and reviewed over time?
