# Governance Checklist

## Curriculum and Learning Pathways

- [ ] Concepts are defined and sequenced.
- [ ] Prerequisites are documented.
- [ ] Learning pathways are explicit.
- [ ] Objectives are connected to concepts and resources.
- [ ] Advanced and remedial pathways are available where needed.

## Objectives, Assessment, and Feedback

- [ ] Learning objectives use clear action language.
- [ ] Assessments align with objectives.
- [ ] Rubrics are connected to assessments.
- [ ] Feedback records connect to assessments.
- [ ] Revision activities connect to feedback.

## Accessibility and Inclusion

- [ ] Visual resources include alt text.
- [ ] Audio/video resources include captions and transcripts.
- [ ] Resources include accessibility metadata.
- [ ] Language and reading level are reviewed.
- [ ] Examples and sources are inclusive.
- [ ] Prior-knowledge bridges exist for foundational gaps.

## Repository and Institutional Memory

- [ ] Learning resources include license notes.
- [ ] Version and revision notes are preserved.
- [ ] Teaching notes and review records are stored.
- [ ] OER records include reuse and adaptation notes.
- [ ] Repository records are linked to resources.

## AI and Data Governance

- [ ] AI-generated learning resources are labeled and reviewed.
- [ ] AI feedback is treated as provisional where appropriate.
- [ ] Learner data is protected.
- [ ] Learning analytics are used for support, not surveillance.
- [ ] Human review remains accountable in consequential settings.
