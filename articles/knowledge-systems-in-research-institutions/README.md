# Knowledge Systems in Research Institutions

This folder contains professional companion assets for the article:

**Knowledge Systems in Research Institutions**

GitHub article folder:

https://github.com/Content-Catalyst-LLC/knowledge-architecture-code/tree/main/articles/knowledge-systems-in-research-institutions

## Purpose

This scaffold models research institutions as knowledge systems: universities, laboratories, libraries, archives, hospitals, research centers, policy institutes, data offices, repositories, and scientific infrastructures.

It focuses on the structures that make institutional knowledge findable, interpretable, reusable, ethically governed, and trustworthy over time.

## Repository Structure

- `python/` — institutional knowledge-system object, metadata, relationship, and stewardship audits
- `r/` — research-system coverage and stewardship diagnostics
- `julia/` — institutional stewardship and reuse-readiness metrics
- `sql/` — schemas for research objects, institutional units, metadata, relationships, repositories, governance records, and revisions
- `rust/` — CLI-style institutional validation scaffold
- `go/` — lightweight institutional coverage utility
- `cpp/` — efficient institutional graph-degree diagnostic example
- `fortran/` — numerical institutional-quality metric example
- `c/` — low-level coverage metric example
- `docs/` — model notes, data dictionary, governance checklist, and runbook
- `data/` — small synthetic institutional datasets
- `outputs/` — expected/generated outputs
