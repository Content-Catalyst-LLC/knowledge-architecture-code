# Governance Checklist

## Metadata and Provenance

- [ ] Every research object has a stable identifier.
- [ ] Every dataset includes creator, project, method, date, restrictions, and provenance.
- [ ] Every software artifact includes environment, license, version, and related publication.
- [ ] Every publication links to supporting data and code where appropriate.

## Repositories and Preservation

- [ ] Institutional repository records are connected to publications and datasets.
- [ ] Repository objects include access rules and preservation status.
- [ ] Code repositories include README, data dictionary, method notes, and outputs.
- [ ] Persistent identifiers are used where appropriate.

## Governance and Integrity

- [ ] Ethics protocols are linked to datasets and publications.
- [ ] Data-management plans are linked to datasets and repositories.
- [ ] Sensitive data is labeled and access-controlled.
- [ ] Community agreements are documented when applicable.
- [ ] Revision records exist for major changes.

## AI Retrieval

- [ ] AI retrieval can distinguish public, restricted, internal, and community-governed records.
- [ ] Retrieval context includes metadata and provenance.
- [ ] AI-facing outputs include status, sensitivity, and limitations.

## Equity and Epistemic Justice

- [ ] Classification terms are reviewed for institutional or disciplinary bias.
- [ ] Community knowledge is not treated as automatically open.
- [ ] Marginalized perspectives and archival silences are documented where relevant.
- [ ] Affected communities have review or governance mechanisms when appropriate.
