# Methodology Notes

This article folder models knowledge graphs as structured systems of nodes, typed semantic relationships, provenance records, and governance metadata. The examples are intentionally small and synthetic, but they are designed to demonstrate professional patterns that can be scaled into larger article-map, research-repository, or AI-retrieval systems.

## Core Modeling Principles

1. Treat articles, concepts, standards, datasets, repository folders, and sources as typed nodes.
2. Treat links as semantic relationships, not generic associations.
3. Preserve provenance for graph edges wherever possible.
4. Separate node definitions, relationship-type definitions, edge assertions, and evidence sources.
5. Make graph quality auditable through reproducible scripts and generated outputs.
