# Model Notes

Knowledge architecture in digital libraries organizes digital collections as meaningful, interoperable, preservable, rights-aware, and ethically governed knowledge systems.

## Core Layers

1. Object layer: books, images, maps, audio, web archives, born-digital files.
2. Collection layer: collections, series, fonds, exhibits, and repository groupings.
3. Metadata layer: descriptive, administrative, technical, preservation, rights, and structural metadata.
4. Semantic layer: subject access, authority control, controlled vocabularies, SKOS concepts, BIBFRAME entities, and linked-data relationships.
5. Preservation layer: fixity, format review, migration, normalization, and authenticity records.
6. Governance layer: cataloging policy, rights review, reparative description, AI metadata review, and description revision history.

## Review Questions

- Do records have sufficient descriptive metadata?
- Do objects have subject access where appropriate?
- Do public records have rights metadata?
- Are objects connected to collection context?
- Are names, places, works, and subjects authority-controlled?
- Are preservation events documented?
- Are harmful, legacy, contested, or community-sensitive descriptions governed?
