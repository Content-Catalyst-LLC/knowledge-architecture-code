# Governance Checklist

- [ ] Every object has minimum descriptive metadata.
- [ ] Every public object has a rights/access statement.
- [ ] Subject access exists where appropriate.
- [ ] Collection context is preserved.
- [ ] Authority records include preferred labels, variants, scope notes, and review status.
- [ ] Preservation events are recorded for long-term objects.
- [ ] Legacy/harmful/contested descriptions have revision pathways.
- [ ] AI-generated metadata is labeled and reviewed.
- [ ] Community-governed or culturally sensitive materials are not treated as automatically open.
