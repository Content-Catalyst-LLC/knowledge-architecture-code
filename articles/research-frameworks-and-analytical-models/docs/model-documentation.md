# Model Documentation

This folder treats a research framework as a structured relationship system.

## Main Objects

- `research_frameworks`: framework identity, version, status, and research problem.
- `model_elements`: concepts, constructs, model components, assumptions, and validation nodes.
- `model_relationships`: named relationships between model elements.
- `evidence_sources`: sources, datasets, documents, or observations linked to framework elements.
- `methods`: analytical procedures used to examine evidence.
- `validation_checks`: quality checks for coherence, coverage, and reproducibility.

## Quality Metrics

- Relationship documentation rate
- Evidence coverage rate
- Role balance
- Underdeveloped element count
- Unlinked evidence count
- Method-framework alignment notes
