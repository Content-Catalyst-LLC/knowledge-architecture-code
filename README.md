# Knowledge Architecture Code Repository

This repository supports the Knowledge Architecture knowledge series with article-level folders, reproducible examples, synthetic datasets, taxonomy models, ontology schemas, semantic-network workflows, knowledge-graph examples, concept-map analysis, research-architecture scaffolds, and scientific-computing examples.

The repository is organized around the article map. Each article folder contains a consistent professional structure for documentation, data, code, notebooks, schemas, ontology assets, taxonomy assets, outputs, tests, and governance notes.

## Repository structure

- `articles/` — article-level folders matching the Knowledge Architecture article map
- `article-map/` — section-level index files generated from the pillar structure
- `data/` — shared raw, processed, and synthetic datasets
- `docs/` — repository-wide documentation
- `governance/` — review logs, taxonomy decisions, and versioning notes
- `graphs/` — shared graph/network artifacts
- `notebooks/` — shared exploratory notebooks
- `ontology/` — shared ontology files and semantic models
- `schemas/` — JSON schemas and metadata definitions
- `sql/` — shared SQL schemas and loading scripts
- `taxonomy/` — controlled vocabularies and taxonomy models
- `tests/` — validation checks
